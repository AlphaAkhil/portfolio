Chess Game

The Chess Game is a 2D turn-based game developed using Python and Pygame, featuring a fully functional chessboard and standard chess rules. Players select and move pieces by clicking source and destination squares, with valid moves and turn order enforced programmatically. The board updates visually after each move, and the game includes basic logic for detecting check and checkmate conditions. This project helped me practice object-oriented programming in Python, implement grid-based movement, and apply core game development principles using Pygame. It serves as a foundational project demonstrating logic implementation, rule-based systems, and game loop control.

2D Spaceship Shooter Game

The 2D Spaceship Shooter Game is a fast-paced arcade-style project developed using Python and Pygame. In the game, the player controls a spaceship that moves horizontally and shoots bullets to destroy incoming enemies falling from the top of the screen. I implemented key features such as sprite movement, bullet firing mechanics, enemy spawning, collision detection, scoring system, and game-over conditions. Graphics were handled using custom or open-source sprites, and sounds were added for shooting and explosions. This project helped me deepen my understanding of game loops, event handling, object-oriented programming, and real-time collision logic in Pygame.
